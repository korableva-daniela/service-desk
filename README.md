# IT-поддержка — Service Desk

Учебный проект: облачная платформа приёма и обработки заявок в IT-поддержку.

## Текущий этап: локальный сайт

Реализованы три страницы:
- `index.html` — форма заявки
- `thank-you.html` — подтверждение приёма
- `status.html` — проверка статуса (пока на демо-данных)

## Запуск

Просто откройте `index.html` в браузере.
